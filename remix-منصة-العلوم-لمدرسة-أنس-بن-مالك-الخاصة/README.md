# منصة العلوم لمدرسة أنس بن مالك الخاصة
### Anas Bin Malik Private School - Science Curriculum Platform

منصة تعليمية متكاملة لمشاركة ورفع الخطط الدراسية، الكتب المدرسية، وأهداف الدروس للصفوف من الخامس حتى الثاني عشر لمواد العلوم (الفيزياء، الكيمياء، الأحياء، العلوم العامة، والعلوم البيئية).

---

## 🌟 المميزات (Features)

- **مكتبة المناهج والخطط الدراسية**: تصفح وتنزيل الخطط الدراسية، الكتب المدرسية، وأهداف ونواتج التعلم لمختلف المراحل والصفوف.
- **تصفية وبحث متقدم**: فلترة فورية حسب المادة، المرحلة الدراسية، نوع المورد التعليمي، والبحث بالكلمات المفتاحية.
- **تكامل مع Google Workspace**: إمكانية تصدير وفتح الملفات مباشرة عبر Google Docs و Google Sheets و Google Drive.
- **تسجيل الدخول للمعلمين**: تكامل مع Firebase Authentication لتسجيل دخول المعلمين وإدارة ومشاركة الملفات.
- **واجهة مستخدم حديثة وسريعة**: مبنية باستخدام React 19، Tailwind CSS، ومكتبة Lucide للأيقونات مع دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Cairo & Tajawal Fonts
- **Icons & Animation**: Lucide React, Motion
- **Authentication**: Firebase Authentication
- **Document Services**: Google Workspace Integration

## 🚀 تشغيل المشروع محلياً (Getting Started)

### 1. استنساخ المستودع (Clone repository)
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

### 2. تثبيت الحزم (Install dependencies)
```bash
npm install
```

### 3. إعداد متغيرات البيئة (Environment variables)
قم بنسخ ملف `.env.example` إلى ملف `.env`:
```bash
cp .env.example .env
```

### 4. تشغيل خادم التطوير (Run development server)
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 5. بناء المشروع للإنتاج (Build for production)
```bash
npm run build
```
